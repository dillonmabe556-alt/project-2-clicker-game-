## Artistic Statement
### Targeted Experience
> i wanted the game to give like a dungeon Cawley feel while still being light hearted. 
### Design Choices
> *Describe your visual style, audio, and UI choices and how they work in coherence
to support your theme.*
- the art style is more pixel art because i like the loke it it can give a more cozy zibe.
- i did not add music to this game 
- simple minimalist UI
- a tresure chest as the generator which generate animatied coins and ugrade buttons.
- a spinning coin for when you clicker the lock and when the chests generate. the lock that has a unlocking animation to represent progressing to the next room
### Game Assets & Placeholders
> *List all art, music, or UI assets that you used to reinforce your theme, and
note any placeholders if you cannot find one that fits.*
- **Core Clicker:** a medieval style lock gotten for itch.io
- the generators are a treasure chest i got off of itch.oi
- the buttons i use are just the basic godot buttons 
- **Decorations:** a dungeon like door
